A deterministic program that writes a single one-line comedy joke (up to 280 characters) to `/output/entry.txt` for make.fun's "One-Liner Marathon" bounty, where a judge model compares entries head to head on how hard they land.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-liner-marathon-25nov-out python3 main.py
```
